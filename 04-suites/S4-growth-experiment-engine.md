# S4 · 增长实验引擎（growth-experiment-engine）

> 来源：`AI营销团队增强报告-v3-136技能.md:308-316` 组合 4（growth engine → A/B → analytics → conversion ops → CRO 审计 → 收入归因）。
> 目标：把「改版/文案/CTA」从拍脑袋变成可证伪实验；每次只动一个变量，有基线、有观察窗、有裁定。

## 启动前置（缺一即不可启动）

| 项 | 判据 | 卡点 |
|---|---|---|
| GA4/GTM 归因配置 | 归因 Phase 1 参数 + 事件分层已在该用户侧发布（`ops/gtm-event-setup.md` 末节） | **G4 用户**（未完成则实验无数据） |
| 基线流量 | 页面 28 天展示 ≥1000（当前全站 2,388，单页需单独判断；低于阈值实验周期不可控） | G9 |
| 转化事件 | `generate_lead` 真实口径（幂等门已上线） | W12 验收 |
| 变更通道 | 走 PR + Gatekeeper + 事实门；实验变体不直推 main | W17/G2 |

## 编排（单实验循环）

### Step 1 · 假设与指标（0.5 天）

- 技能：`es-growth-engine`、`ab-testing`、`analytics`。
- 输入：W19 看板数据、W20 诊断、W12 漏斗断点。
- 输出假设卡（必须含 6 字段）：现状数据 / 假设（若改 X，则 Y 提升）/ 指标（主 1 + 次 2）/ 最小可检出效应 / 观察窗 / 反悔条件。
- 产出：`$D/step-1-hypothesis.md`。
- 验收：主指标是**比率**（CTR/提交率/线索率），不是总量；观察窗 ≥14 天（低流量）。

### Step 2 · 变体实现（1–2 天）

- 技能：`cm-landing-page-optimizer`、`cm-cro-auditor`、`copywriting`、`stop-slop`。
- 范围：优先「单页单变量」（title/meta、CTA 文案、表单字段数、信任条位置）。
- 实现走 W6/W20 分支 → W17 门禁 → W21 发布后验收。
- 产出：`$D/step-2-variant.md`（改动 diff 摘要 + PR 号 + 部署时间）。
- 验收：只动一个变量；其他元素与基线逐字节一致（diff 证明）。

### Step 3 · 数据采集（≥14 天）

- 技能：`analytics`、`cm-google-analytics`、`es-conversion-ops`。
- 数据源：GSC 页面维度（展示/CTR/位次）+ GA4（form_submit/generate_lead/inquiry_view）+ D1 询盘。
- 注意：GSC 有 2–3 天延迟；同一周内不得叠第二个实验。
- 产出：`$D/step-3-data.json`（逐日序列）。

### Step 4 · 裁定（三态）

| 裁定 | 条件 | 动作 |
|---|---|---|
| 采纳 | 主指标提升 ≥ 阈值且方向一致 2 周 | 保留变体，写入 W20 台账 |
| 否决 | 主指标下降或持平 | 回滚变体，记录「假设失败」 |
| 不确定 | 样本不足（<100 展示或 <10 提交） | 延长 1 周或换更大流量页，**不下结论** |

- 产出：`$D/step-4-verdict.md`（数据表 + 裁定 + 理由）。
- 验收：裁定能被第三方用同一数据复算。

### Step 5 · 归因与收入视角（可选，需 D1 归因）

- 技能：`es-revenue-intelligence`、`cm-cro-auditor`。
- 用 D1 `attr_first/attr_last` 看变体页是否改变「内容→询盘」路径（`ops/attribution-model.md:184-200`）。
- 产出：`$D/step-5-revenue.md`。

## 套件级验收（一个实验周期）

- [ ] 假设卡 6 字段齐全，主指标为比率，观察窗 ≥14 天。
- [ ] 变体只动 1 个变量（diff 为证）。
- [ ] 有逐日数据序列，不是只看首尾。
- [ ] 三态裁定之一 + 可复算依据。
- [ ] 结果入 W16 月复盘与 W20 台账，不重复试同一假设。

## 失败处理

| 失败 | 处置 |
|---|---|
| 后台归因未配置 | 套件不启动；先推进 G4，改为「观察性分析」不算实验 |
| 流量不足 | 选全站级指标（如 /blog/ 列表 CTR）或延长观察窗；不硬做单页小样本 |
| 同期并行改动污染 | 记录污染点，实验作废重跑；禁止「差不多就行」 |
| 变体被 Gatekeeper 拦 | 按 W17 ⑥ 处理，不绕过门禁 |
